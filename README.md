# FocaEstudo 📚

Rastreador de estudos com foco, desenvolvido em Java Swing.

## Funcionalidades
- Cronômetro e Timer Pomodoro
- Adição manual de tempo
- Gráfico de pizza com distribuição por matéria
- Histórico de sessões
- Metas diárias por matéria
- Cores personalizáveis por matéria

## Como executar
1. Certifique-se de ter o Java instalado
2. Clone o repositório
3. Execute o arquivo `Executar_Programa.bat`

## Tecnologias
- Java 11+
- Java Swing
